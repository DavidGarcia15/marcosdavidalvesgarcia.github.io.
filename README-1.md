# assets/

Esta pasta é o lugar para imagens e arquivos autorizados do portfólio: por
exemplo, uma foto de perfil (opcional) ou imagens de certificados já revisadas
(sem dados pessoais desnecessários visíveis).

Sugestões antes de adicionar qualquer arquivo aqui:

- Comprima imagens grandes (menos de ~300 KB cada, quando possível) para o
  site carregar rápido mesmo em conexões lentas.
- Se for usar uma foto de certificado, confira se ela não expõe CPF, data de
  nascimento completa, QR Code de verificação com dados sensíveis ou outras
  informações que não precisam ser públicas. Recorte ou borre essas partes
  antes de publicar.
- Nomeie os arquivos de forma descritiva e sem espaços, por exemplo:
  `marcos-foto-perfil.jpg`, `certificado-obgp-2026.jpg`.

Depois de adicionar uma imagem aqui, referencie-a nas páginas HTML com um
caminho relativo, por exemplo `<img src="../assets/marcos-foto-perfil.jpg" alt="...">`,
e lembre-se de preencher o atributo `alt` com uma descrição útil da imagem.
